## 🛠️ Built With

- **Nuxt 2** (Vue.js, `target: static`)
- **Three.js** for the WebGL canvas scenes
- **GSAP** for animation
- **Sass** for styling
- Deployed on **Vercel**

## 🚀 Run Locally

```bash
git clone https://github.com/muneebrahmancmd/muneeb-rehman-portfolio-2.0.git
cd muneeb-rehman-portfolio-2.0
npm install
npm run dev       # local dev server at localhost:3000
npm run build     # production build
npm run generate  # fully static output
```

The build scripts already include `NODE_OPTIONS=--openssl-legacy-provider`, which Nuxt 2 needs on Node 17+.
